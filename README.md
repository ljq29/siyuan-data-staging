# 文件暂存

思源文档块插件：把文件或文件夹拖入“文件暂存”块，像网盘一样管理，并通过思源工作空间和同步机制在各设备间传递文件。

## 要求

- 思源 `3.8.10` 或更高版本（依赖 `NodeCustomBlock`）
- 每个需要使用暂存块的设备都要安装并启用本插件
- 单文件最大 `200 MiB`
- 文件夹 ZIP 下载的内容总量最大 `512 MiB`

## 安装

从 [GitHub Releases](https://github.com/ljq29/siyuan-data-staging/releases/latest) 下载 `siyuan-data-staging.zip`，将其中的 `siyuan-data-staging` 目录解压到当前工作空间的 `data/plugins/`，然后重新加载思源并在插件设置中启用“文件暂存”。

本地执行 `pnpm run package` 后，也可以直接把本目录中的 `plugin.json`、`index.js`、`index.css` 和 `README.md` 放入 `data/plugins/siyuan-data-staging/`。

### 从旧版本升级

- 从 `0.3.x` 升级：直接替换插件目录并重新加载思源即可。插件 ID、块标识符和 `data/staging/` 目录都没有变化，已有暂存块无需迁移。
- 从 `0.2.x` 升级：旧版插件名为 `data-staging`。安装新版后，在源码仓库执行以下命令迁移已有块，再重新加载思源并移除旧插件目录：

```sh
SIYUAN_BASE_URL=https://example.com SIYUAN_TOKEN=your-token pnpm run migrate:legacy
```

迁移脚本只把精确匹配的旧标识 `;;;data-staging/data-staging` 更新为 `;;;siyuan-data-staging/siyuan-data-staging`，保留块 ID、块内容和 `data/staging/` 中的文件。执行前请备份工作空间。

## 使用

1. 在文档中输入 `/文件暂存` 并选择带图标的命令，旧的 `/数据暂存` 别名仍可使用。
2. 默认以图标网格展示，可切换为列表视图；列表视图显示名称、大小和修改时间，宽屏下还显示类型。
3. 将文件或文件夹拖到文件展示区域，或点击“添加文件”。拖入时展示区域会高亮；拖入文件夹时保留其中的文件层级，空目录可能被工作空间清理。
4. 点击“新建文件夹”创建目录，双击文件夹进入，使用顶部面包屑返回；也可以把文件直接拖到某个文件夹上，上传到该目录。
5. 单击选中项目，Ctrl/Cmd 单击多选，Shift 单击连选，Ctrl/Cmd+A 全选当前列表；选中后标题行下方出现工具栏，可下载、重命名、删除。
6. 右侧详情面板显示类型、大小、修改时间、实际存储名和相对路径，并提供下载、重命名、删除按钮；点击标题行的详情图标可收起面板，窄屏下面板移到底部。
7. 拖动已暂存的条目到文件夹或面包屑，即可移动位置；显示名和大小记录会一并迁移。
8. 工具栏支持按名称、修改时间、大小、类型排序，以及按显示名或实际存储名搜索当前目录。
9. 重命名只修改名义名称，不改变实际存储路径；下载时使用显示名称。
10. 文件可直接下载；文件夹和当前目录会打包为 ZIP 下载，ZIP 内使用显示名称并保留目录结构。
11. 同名文件确认后才会覆盖。删除文件夹会同时删除其中全部内容，操作前需要确认。
12. 使用“刷新”读取其他设备同步过来的变化。

快捷键（焦点在暂存块内时）：`F2` 重命名、`Delete` 删除、`Enter` 打开选中的文件夹、`Esc` 取消选择或退出编辑。

每个块对应一个独立目录：`工作空间/data/staging/<块ID>/`。目录扫描结果是文件和文件夹的事实来源；根目录下的 `.data-staging.json` 保存显示名映射和文件大小记录，不会显示在文件列表中。

删除文档中的暂存块**不会自动删除**对应目录和文件，以防误删。不再需要时可在块内逐个删除，或在确认块 ID 后手动清理目录。

## 同步与限制

- 文件写入后由思源原有同步机制处理，请确保工作空间已启用同步。
- 插件不建立历史版本，但思源同步自身仍可能保留云端快照。
- 两台设备同时修改同名文件时，最终内容取决于同步结果；不要在多设备上同时编辑同一个暂存文件。
- 文件大小只在上传（含覆盖上传）时写入元数据，下载和预览不会为了显示大小而读取文件内容；`0.3.x` 及更早版本上传的旧文件没有记录，显示为“未记录”。
- 通用文件接口会将文件读入内存，因此单文件限制为 `200 MiB`，不适合大型网盘用途；下载大文件时内核和浏览器都会占用相应内存。
- ZIP 在浏览器内生成，内容总量限制为 `512 MiB`，下载大目录时会占用相应内存。
- `/data/staging/` 位于工作空间内，会参与思源同步；放入大量或大体积文件会拖慢同步。
